# Ember Research Lab

Independent lab building security and memory infrastructure for AI agents, in Rust.

## Engineering

- [ember-agent-monitor](https://github.com/ember-research-lab/ember-agent-monitor): runtime observer between a coding agent and its APIs; detection rules, with observe, warn or block responses.
- [claude-cortex](https://github.com/ember-research-lab/claude-cortex): MCP server for BM25 and spectral retrieval over a hash-chained knowledge ledger.
- [ember-graph](https://github.com/ember-research-lab/ember-graph): zero-dependency knowledge-graph engine with token-budgeted traversal.
- [vetpkg](https://github.com/ember-research-lab/vetpkg): zero-dependency supply-chain proxy that scores npm installs at install time.
- [ember-crypto](https://github.com/ember-research-lab/ember-crypto): sign/verify layer with Ed25519, ML-DSA-65 and hybrid schemes; unknown algorithms fail closed.
